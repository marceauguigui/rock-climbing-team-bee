How to use it: your own code detects the corner markers in a real camera's image and computes that camera's pose (rvec, tvec); enter it (step 3), load a photo taken by the same camera at the same resolution: the outline drawn from your parameters must fall on the real board and markers. Then save the cameras for the simulator.
